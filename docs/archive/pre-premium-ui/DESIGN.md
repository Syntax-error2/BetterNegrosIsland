## Composition and typography

Use one primary self-hosted **Plus Jakarta Sans** family, licensed under its bundled open-font license. Weights 400/500/600/700; system fallback while loading. No runtime Google Fonts requests. Headline 36–52px, page title 28–36px, sections 20–24px, body 16px, dense records 14px, supporting text and labels 12–13px. Use tabular numerals for money, calm weight and restrained tracking. The regional stylesheet overrides predecessor typography; the previous assets and QA evidence remain historical artifacts.

White data surfaces, cool off-white page, civic navy text, the supplied royal-blue logo identity, and restrained teal distinguish series. Status meaning remains in words; increases/decreases are not framed as good/bad. Borders and alignment carry structure. Avoid shadows except useful tooltip separation. Page grid is approximately 1320px with responsive gutters. The hero is compact, followed immediately by snapshot provenance and useful figures.

No measured bundle-size comparison among these libraries is claimed. The chart module is a route chunk, not part of the initial summary. Exact current build measurements are in the QA report.
