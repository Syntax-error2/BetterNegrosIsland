# Master layout design plan — 3 November 2026

The visual anchor is the supplied landscape and wordmark: sugarcane, mountain, water and sunburst. The interface should resemble an accessible public evidence workspace, with a compact institutional header and a prominent paired-budget review. Preserve Plus Jakarta Sans, exact financial data and source caveats.

Palette: civic navy #10243f; water blue #085b8b; document white #ffffff; cool paper #f5f7fa; rule #d7e0e8; text #122b43. Existing logo colors remain the source of brand identity. Use one typeface, tabular financial numbers, sentence-case labels, quiet dividers and readable text widths.

Desktop: `[wordmark | navigation | source status]`, then `[headline + actions (65%) | budget versions + source dates (35%)]`, then a four-part KPI group, then communities. Footer: `[brand | explore | information | accountability]`, followed by concise evidence caveat, expandable original source notice and bottom attribution/operator bar. Mobile stacks the hero, keeps the review visible, and uses a disclosure menu and 2/1-column footer groups.

Containers: wide dashboards/tables up to 1520px usable width, standard pages up to 1352px, reading pages approximately 76 characters. Gutters 16–32px; spacing tokens 4,8,12,16,20,24,32,40,48,64px.

Critique before implementation: a newspaper treatment, oversized year and repeating uppercase labels would compete with the actual civic branding. Keep the established family, make the budget versions the key visual in the review panel, remove duplicate metadata strips, and spend emphasis on the real logo. Do not add decorative regional illustrations, false number counters, or a motion library for basic opacity/transform transitions. Use one short KPI entrance and user-triggered feedback, with reduced motion disabling movement.
