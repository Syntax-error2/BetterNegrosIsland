# Public records tools

The four pages use dated extracts separate from the portal’s budget snapshot. The public deployment policy supports direct links to each page. Pinned snapshot mode asks readers to switch to the current supporting index before opening them.

| Route | Source and selection |
|---|---|
| `/budget-stages` | The [BetterGov.PH and People’s Budget Coalition Senate comparison CSV](https://budget-assets.bettergov.ph/hgab/2027/mpb-years/senate.csv) dated 2026-11-23 contains 5,807 national lines. The portal selected all 240 rows labeled Negros Island Region and matched all 240 House IDs and quoted House amounts against the retained DPWH proposal data. All 31 marked cuts have a report page link. The extract stores the original CSV SHA-256 and the comparison snapshot ID. A missing NEP amount is null. The three stages are alternate proposal amounts for the same House-line cohort. Use the [Senate portal](https://budget-transparency-portal.senate.gov.ph/) for the legislative source. |
| `/procurement` | Exact Bacolod and Vallehermoso buyer names from [one BetterGov.PH PhilGEPS API response](https://visualizations.bettergov.ph/api/philgeps/v2/awards?search=BACOLOD&page_size=100&page=1) retrieved 2026-11-25. Only the award reference, date, title, buyer, awardee, and amount are included. Exact duplicates are discarded. The [national export documentation](https://github.com/bettergovph/open-data-visualization/blob/main/data/philgeps-v2/README.md) gives source coverage and explains the assumed PHP currency. The archived query sample covers selected results only. |
| `/site-evidence` | 24 sampled identifiers from the retained DPWH contract explorer build dated 2026-11-03. The second reading was retrieved on 2026-11-25 from the BetterGov.PH DPWH projects API. Each response was selected by exact contract ID and paired with its Bisto project route. Official figures record agency-reported status and progress. Any citizen observations remain at [Bisto](https://bisto.ph/). |
| `/local-disclosures` | The existing PSGC place list pairs with 14 source entries checked on 2026-11-25. Source issuers include [Bacolod City](https://bacolodcity.gov.ph/full-disclosure-policy/), [Dumaguete City](https://dumaguetecity.gov.ph/transparency/), [Negros Occidental](https://www.negros-occ.gov.ph/transparency/), and the [Commission on Audit](https://www.coa.gov.ph/reports/annual-audit-reports/). The document year and source check date have separate meanings. Directory counts refer to index entries, with no compliance rating. |

The arrays in `src/data/civic/` are reviewed with each change. Before refreshing, confirm region, buyer, document jurisdiction, and contract IDs against the original sources. Reconcile duplicate or conflicting records before publishing, retain source dates, and run `npm run verify`. Review and deployment follow the portal’s existing process.

## Project timeline, local spending, funding and bids

| Route | Source and reconciliation |
|---|---|
| `/project-timeline` | The same 24 contracts as the site evidence pilot, joined to the retained ledger and BetterGov.PH’s DPWH API responses by exact contract ID. Contract and procurement fields were checked on 2026-11-25. Date fields with incomplete award details keep source-qualified labels. Four records have listed award documents. GAA links retain their candidate status. All 24 public Bisto project pages showed zero reports when checked on 2026-11-25. |
| `/lgu-spending` | FY2025 current operating expenditures reported by the [Bureau of Local Government Finance](https://blgf.gov.ph/lgu-fiscal-data/) and compiled on [Scene.ph](https://scene.ph/atlas/sources/lgu-income). All 63 city and municipality profiles were checked on 2026-11-25 by name, province, and fiscal year, then keyed to the existing PSGC directory. The regional view retains the compilation’s displayed rounding and a source link for each place. |
| `/lgu-spending?view=comparison` | [Bacolod Q4 2025 Statement of Receipts and Expenditures](https://bacolodcity.gov.ph/wp-content/uploads/2022/08/2025_4thsre.xls), sheet `sre_report`, rows 25–32 and 48. Budget appropriation comes from column D and reported total expenditures from I. Subtotals reconcile to rows 33 and 56, and column I reconciles to the four reported fund columns. The separate [2025 Annual Budget workbook](https://bacolodcity.gov.ph/wp-content/uploads/2022/08/2025_ABR.xlsx), sheet `LBP Form 1`, cell S222, provides the proposed General Fund figure as context. The embedded records retain both workbook hashes and the report period. |
| `/fund-releases` | 63 selected entries from the [DBM 2026 SARO register](https://www.dbm.gov.ph/wp-content/uploads/SARO/UPDATED_SARO.PDF) checked on 2026-11-25. The extract covers selected departmental records with a NIR issuance code or a named regional operating unit or location in the purpose. Rows preserve signed values, release date, source page, department, agency, operating unit, and purpose. A mutable PDF can move a row to another page. Search its exact order number if the page changes. |
| `/fund-releases?view=assistance` | [DBM COMPASS FALGU](https://compass.gov.ph/lgsf/falgu) FY2026 v7 public CSV, as of 2026-09-30, exported with the Negros Island Region filter. 83 source rows form 81 groups of identical values, with the original repeat counts retained. 49 cities and municipalities are named. The place filter matches the locality within the source province. A province-only record stays at province level. SARO and NCA are shown separately. The export does not supply an order number, issue date, or payment. |
| `/procurement?view=bids` | Ten official PhilGEPS printable abstracts with exact Bacolod or Vallehermoso buyer names, checked 2026-11-25. Dates and deadlines show local Philippine time. Bid records `11702603` and `11702570` have outcomes corroborated by an exact solicitation and approved-budget match in the [city’s Q1 2025 bid results](https://bacolodcity.gov.ph/wp-content/uploads/2022/08/2025_1stbids.xlsx), `bid out` rows 21 and 22. The winning bid amount has its own label. The separate [BetterGov.PH award sample](https://visualizations.bettergov.ph/philgeps) remains accessible via the Award records view. |
