# Public records tools

The four pages use dated extracts separate from the portal’s budget snapshot. The public deployment policy supports direct links to each page. Pinned snapshot mode asks readers to switch to the current supporting index before opening them.

| Route | Source and selection |
|---|---|
| `/budget-stages` | The [BetterGov.PH and People’s Budget Coalition Senate comparison CSV](https://budget-assets.bettergov.ph/hgab/2027/mpb-years/senate.csv) dated 2026-11-23 contains 5,807 national lines. The portal selected all 240 rows labeled Negros Island Region and matched all 240 House IDs and quoted House amounts against the retained DPWH proposal data. All 31 marked cuts have a report page link. The extract stores the original CSV SHA-256 and the comparison snapshot ID. A missing NEP amount is null. The three stages are alternate proposal amounts for the same House-line cohort. Use the [Senate portal](https://budget-transparency-portal.senate.gov.ph/) for the legislative source. |
| `/procurement` | Exact Bacolod and Vallehermoso buyer names from [one BetterGov.PH PhilGEPS API response](https://visualizations.bettergov.ph/api/philgeps/v2/awards?search=BACOLOD&page_size=100&page=1) retrieved 2026-11-25. Only the award reference, date, title, buyer, awardee, and amount are included. Exact duplicates are discarded. The [national export documentation](https://github.com/bettergovph/open-data-visualization/blob/main/data/philgeps-v2/README.md) gives source coverage and explains the assumed PHP currency. The archived query sample covers selected results only. |
| `/site-evidence` | 24 sampled identifiers from the retained DPWH contract explorer build dated 2026-11-03. The second reading was retrieved on 2026-11-25 from the BetterGov.PH DPWH projects API. Each response was selected by exact contract ID and paired with its Bisto project route. Official figures record agency-reported status and progress. Any citizen observations remain at [Bisto](https://bisto.ph/). |
| `/local-disclosures` | The existing PSGC place list pairs with 14 source entries checked on 2026-11-25. Source issuers include [Bacolod City](https://bacolodcity.gov.ph/full-disclosure-policy/), [Dumaguete City](https://dumaguetecity.gov.ph/transparency/), [Negros Occidental](https://www.negros-occ.gov.ph/transparency/), and the [Commission on Audit](https://www.coa.gov.ph/reports/annual-audit-reports/). The document year and source check date have separate meanings. Directory counts refer to index entries, with no compliance rating. |

The arrays in `src/data/civic/` are reviewed with each change. Before refreshing, confirm region, buyer, document jurisdiction, and contract IDs against the original sources. Reconcile duplicate or conflicting records before publishing, retain source dates, and run `npm run verify`. Review and deployment follow the portal’s existing process.
